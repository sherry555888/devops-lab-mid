# DevOps Assignment Submission Portal

## How to Run Application Locally
1. Install dependencies: `npm install`
2. Start server: `npm start`
3. Access portal at: `http://localhost:3000`

## How to Start HTTP Receiver
1. Run command: `npm run receiver` (Listening on http://localhost:4000/report)

## How to Execute Automated Tests
1. Run tests manually: `npm test`
